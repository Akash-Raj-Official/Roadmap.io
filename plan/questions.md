# Product Decisions Needed

Please answer these in whatever format is easiest; short answers are enough.

1. Who can use the site at launch: anyone without signing in, registered learners, or only an admin-managed audience?
2. Will there be one administrator or multiple administrators/editors? Do you need different roles such as editor and publisher?
3. Should learners be able to mark topics complete and see a percentage/progress dashboard in the first release?
4. How should a roadmap look: a simple ordered checklist/timeline, a branching visual graph, or both?
5. Must topics be reusable across several roadmaps? For example, should a single Docker topic appear in both DevOps and Cloud Engineering?
6. What content belongs on a topic besides its title: description, curated resource links, videos, tasks/projects, notes, difficulty, or estimated learning time?
7. Will you create all roadmap content manually, import it from a file, or eventually let AI help generate initial topics/resources?
8. Do you have a preferred authentication provider or should the first version use an email/password admin account?
9. Is the public site a portfolio/community project, or will it later need monetization, subscriptions, or private roadmaps?
10. For AWS phase 2, do you want the EC2 deployment primarily as a learning exercise or as the intended long-term production host?
